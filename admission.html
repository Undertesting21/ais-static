Admission Requirements

📚 Kindergarten

  • PSA Birth Certificate
  • Filled-out Enrollment Form (ECCD Form)
  • Medical / Health Record (if required)
  • 1–2 pcs 2x2 ID picture
  • Parent/Guardian ID

📘 Elementary (Grade 1–6)

  • PSA Birth Certificate
  • Report Card (Form 138) (for incoming Grade 1, if applicable)
  • School Records (for transferees)
  • Good Moral Certificate (if applicable)
  • 2x2 ID pictures
  • Enrollment Form
  • Parent/Guardian ID

📗 Junior High School (Grade 7–10)

  • PSA Birth Certificate
  • Report Card (Form 138)
  • Form 137 (Permanent Record) (for transferees)
  • Good Moral Certificate
  • Certificate of Completion (for Grade 6 graduates)
  • 2x2 ID pictures
  • Enrollment Form
  • Parent/Guardian ID

📕 Senior High School (Grade 11–12)

  • PSA Birth Certificate
  • Report Card (Form 138)
  • Form 137 (Permanent Record)
  • Certificate of Completion (Grade 10)
  • Certificate of Good Moral Character
  • 2x2 ID pictures
  • Enrollment Form
  • Parent/Guardian ID
